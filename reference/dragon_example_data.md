# Path to the bundled example dataset

Two hundred synthetic customer-support tickets with `subject`, `body`,
`product`, and `reply` columns. Small enough to train on a CPU in
minutes.

## Usage

``` r
dragon_example_data()
```

## Value

A file path.

## Examples

``` r
dragon_example_data()
#> [1] "/home/runner/work/_temp/Library/dragonfarm/extdata/support_tickets.jsonl"
```
